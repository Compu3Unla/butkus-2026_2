# Butkus Camera Manual Library

## Rediseño y desarrollo web — Trabajo práctico grupal

## Descripción del proyecto
El proyecto consiste en el rediseño y desarrollo de una propuesta web para Butkus Camera Manual Library, una biblioteca digital dedicada a la conservación y consulta de manuales de cámaras fotográficas.

Se trabajó en la reorganización de la información, la construcción de una identidad visual y el diseño de interfaces para mejorar la navegación, la jerarquía visual y la experiencia de usuario.
La propuesta fue desarrollada inicialmente en Figma y posteriormente trasladada a código mediante HTML5 y CSS.

## Resultado final
El sitio web final contiene 8 páginas (Index, Conocenos, Documentos, Donación, Inicio Sesión, Inicio Sesión Contraseña, Videoteca y Usuario) en su formato escritorio y 1 en su adaptación mobile (index). Las mismas contienen:
- Animaciones
- Galería de imágenes
- Formularios
- Archivos multimedia (optamos por el uso de videos)
- Favicon
- Ayudante inteligente
- Fondos animados
- javascript (para carruseles)
